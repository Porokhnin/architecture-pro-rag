## Анализ логов

Бот хорошо справился с вопросами по темам, имеющимся в базе знаний. 
По неизвестным темам, сразу говорил, что не знает, однако все равно находились какие-то документы (chunks).

Для дальнейшего улучшения бота необходимо расширение тем и дальнейшее обучение.

Оценка проводилась достаточно просто:
Был сформирован файл с золотыми вопросами и ключевыми словами ответа на него.
Дальше боту задавался вопрос и сверялся факт наличия ключевого слова ответа.

Метод анализа проводился в ручном режиме и на ограниченно количестве вопросов. Однако при большой базе знаний необходимо будет огромное количество вопросов.
Рекомендуется использовать генерацию возможных вопросов по базе знаний, с дальнейшей проверкой качества ответов. Использование метрик для улучшения базы знаний и ответов бота. Рекомендуется рассмотреть RAGAS для этих целей.
